# MLModel-Trainer-Evaluator

A simple and interactive Machine Learning web application built with Python and Streamlit. Users can upload a CSV dataset, select a machine learning task, choose a model, train it, and view the model's performance.

Install the required libraries:
pip install streamlit pandas scikit-learn seaborn matplotlib

Run the following command:
streamlit run main.py

This project is created as a Machine Learning mini project to understand how different ML algorithms can be trained and evaluated through an interactive web interface.
